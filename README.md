# JARVIS V11

A phone-first personal JARVIS web app.

## What works now
- Text commands
- Voice commands (browser support required)
- Foreground wake mode using “Jarvis”
- Open YouTube, Google, Instagram and GitHub
- Google search commands
- Local tasks
- Local projects
- Local memory
- Briefing summary
- PWA install support
- Updated service-worker cache version

## Important
This is a browser PWA. A true always-on wake word while the phone is locked or the app is in the background requires a native Android app and an Android foreground/background audio service.

Replace the old repository website files with these V11 files.
